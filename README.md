# BrainFOck

Pythonで実装した、シンプルなBrainfuckインタプリタです。

Brainfuckの8つの命令を解釈し、指定した `.bf` ファイルを実行します。サンプルとして、Hello Worldを出力する `hw.bf` などを収録しています。

## 必要環境

- Python 3

外部ライブラリは使用していません。

## 使い方

リポジトリをクローンし、`main.py` を実行します。

```bash
git clone https://github.com/Aryudesu/BrainFOck.git
cd BrainFOck
python main.py
```

ファイル名を尋ねられるので、実行するBrainfuckプログラムのパスを入力してください。

```text
FileName > hw.bf
Hello, World!
```

## 対応する命令

| 命令 | 動作 |
| --- | --- |
| `+` | 現在のセルの値を1増やす |
| `-` | 現在のセルの値を1減らす |
| `>` | データポインタを右へ移動する |
| `<` | データポインタを左へ移動する |
| `.` | 現在のセルの値を文字として出力する |
| `,` | 1文字入力し、その文字コードを現在のセルへ格納する |
| `[` | 現在のセルが0なら、対応する `]` の直後へ移動する |
| `]` | 現在のセルが0でなければ、対応する `[` の直後へ移動する |

上記以外の文字は無視されるため、Brainfuckコード内にコメントとして通常の文字を含めることもできます。

## 実装上の仕様

- メモリは右方向へ必要に応じて自動的に拡張されます。
- セルの値はPythonの整数として扱われ、8ビットでのオーバーフローやアンダーフローは行いません。
- メモリの左端より左へポインタを移動すると、ポインタエラーになります。
- 対応する括弧が存在しない場合は、括弧エラーになります。
- 指定したファイルが存在しない場合は、ファイルが存在しない旨のエラーになります。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `main.py` | Brainfuckインタプリタ本体 |
| `importFile.py` | 入力ファイルの存在確認 |
| `error.py` | 独自例外の定義 |
| `hw.bf` | Hello Worldのサンプル |
| `cord.bf` | Brainfuckプログラムのサンプル |
